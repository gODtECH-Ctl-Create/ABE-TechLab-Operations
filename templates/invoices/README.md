# Invoice Templates

This directory stores invoice template assets used by the ABE TechLab Operations invoice system.

## Template Asset

Place the approved invoice design template here, preferably as a PDF. The template should be a clean, reusable design asset rather than a completed client invoice containing private financial or client information.

Recommended filename:

```text
abe-techlab-invoice-template.pdf
```

## Intended Use

The future invoice generator will use the template as the visual reference for:

- Invoice layout
- Typography
- Spacing
- Tables and financial summary
- Watermark treatment
- Brand colors
- Notes and terms section

Keep template-specific assets in this directory so they remain separate from application logic.
